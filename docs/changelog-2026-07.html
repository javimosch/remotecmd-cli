Changelog

July 2026

🚇

Port forwarding & background tunnels

Reach services that only listen on a target's loopback: tunnel start --local P --remote host:port forwards a local port through the relay — with -daemon it survives your CLI exiting, and tunnel status / tunnel stop manage it.

❤️

Fleet health checks

list-targets now probes targets you haven't seen in a while, so the fleet view shows who is actually alive — --refresh forces a full re-probe.

🔄

Self-update

remotecmd-cli update upgrades the CLI itself to the latest GitHub release — sha256-verified, with --check to preview and a backup of the old binary.

🤖

MCP server

New remotecmd-cli mcp subcommand speaks the Model Context Protocol, so AI agents can list targets and run commands natively — no shell parsing required.

📦

Chunked file transfer

cp now chunks large transfers instead of stalling — multi-megabyte files and directories move reliably across flaky links.

💬

Feedback built in

remotecmd-cli feedback reports bugs and ideas straight to the relay — the same contract as other machin tools, so agents can file issues in-band.
