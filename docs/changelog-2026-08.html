Changelog

August 2026

⚡

Dramatically faster file transfers

Parallel TCP streams, adaptive gzip compression and tuned buffers took a 10 MB transfer from ~16 s to ~0.3 s. Transfers auto-tune stream count by file size — no flags needed.

🔐

Relay authentication & TLS

Relays can now require a shared secret (RELAY_SECRET) and terminate TLS — opt-in and backward compatible, with an exempt-name list for nodes that must join without the secret.

🔑

Stronger pairing

Activation keys gate who can claim a pair code, pair disconnect revokes a target, and a container sidecar endpoint lets Docker hosts onboard without a shell.

🏗️

Static binaries for Alpine

Every release now ships linux-*-static builds that run on musl/Alpine containers where the dynamic binary can't.

🧪

CI coverage gate

Tests run on every push with a 40% coverage floor — regressions get caught before release.

🧹

Memory-leak fixes

Closed writers on disconnect and cleared file-transfer reassembly on reconnect — long-lived daemons stay lean.
