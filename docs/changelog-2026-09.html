Changelog

September 2026

🪟

Windows 10/11 support

Targets on Windows now work end-to-end — scheduled-task boot persistence, a Windows updater with rollback helper, and release binaries for amd64 and arm64.

🔁

In-place daemon updates

daemon update and relay daemon update upgrade the binary a running daemon actually executes and re-exec it in place — same PID, in-flight commands finish, no dropped registrations. Fleet-wide: rcx --group.

🏷️

Version transparency

Daemons announce their version on register; list-targets shows a VERSION column, help-json catalogs every command, errors are typed JSON, and an embedded guide teaches agents the tool.

🛡️

Security hardening

Relay now blocks target-name hijacking, token checks are constant-time, connections have keepalive pings, and dials/handshakes are time-bounded — a wedged node can't hold the relay hostage.

🩺

Relay operations

relay daemon start --host, /_health endpoint, daemon status --json, and named --name daemon instances for running several daemons on one machine.

🐛

Reliability sweep

Tunnel reconnects instead of dying silently, updates verify sha256 and fail closed, static builds install correctly, and processes in other containers are never signalled.
